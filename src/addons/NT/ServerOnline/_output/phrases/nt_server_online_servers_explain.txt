One row per server. Choose the game and enter the server address as <code>host:port</code>. The port can be left out when the server uses the default one. For <b>JSON API</b> enter the address that returns the server status as JSON. The name is optional: when it is empty, the name reported by the server is used. The path is used by JSON API only, when the server data is nested inside the response, for example <code>data.servers.0</code>.
